# PortifyStudio Portfolio

A modern, responsive, and production-ready personal portfolio website built with HTML, CSS, and JavaScript. This project is optimized for performance, SEO, and mobile devices, serving as an excellent template for developers and a robust foundation for SaaS products.

## 🚀 Features

- **Responsive Design**: Fully adaptable to mobile, tablet, and desktop screens using Flexbox/Grid.
- **SEO Optimized**: Includes meta tags, Open Graph tags, semantic HTML, and proper heading structures.
- **High Performance**: Optimized assets, minimal code, and fast loading times.
- **Clean Architecture**: Modular and maintainable folder structure.
- **Cross-Browser Compatible**: Works seamlessly across all modern web browsers.

## 🛠️ Tech Stack

- **HTML5**: Semantic and accessible markup.
- **CSS3**: Modern styling with Flexbox, CSS Grid, and media queries.
- **Vanilla JavaScript (ES6+)**: Interactive UI elements without heavy frameworks.

## 💻 Installation Steps

To run this project locally, follow these simple steps:

1. **Clone the repository:**
   ```bash
   git clone https://github.com/portifystudio/portfolio.git
   ```

2. **Navigate to the project directory:**
   ```bash
   cd portfolio
   ```

3. **Open the project:**
   Simply open the `index.html` file in your preferred web browser, or use a tool like [Live Server](https://marketplace.visualstudio.com/items?itemName=ritwickdey.LiveServer) in VS Code for live reloading.

## 🌐 Deployment (Vercel)

Deploying a static HTML/CSS/JS site to Vercel is quick and easy.

1. **Push your code to GitHub:** Make sure your project is pushed to a GitHub repository.
2. **Log in to Vercel:** Go to [Vercel](https://vercel.com/) and log in with your GitHub account.
3. **Add New Project:** Click the "Add New..." button and select "Project".
4. **Import Repository:** Find your portfolio repository in the list and click "Import".
5. **Configure Project:** 
   - Framework Preset: Leave as `Other`
   - Root Directory: `./`
   - Build Command: Leave blank (not needed for static sites)
   - Output Directory: Leave blank
6. **Deploy:** Click the "Deploy" button. Vercel will automatically build and publish your site globally in seconds!
