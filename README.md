# Network Developer Portfolio

A professional, modern, and responsive personal portfolio website for a Network/Security Engineer. Built with React 18, Vite, and Tailwind CSS, this project features smooth animations and a clean, dark-themed UI optimized for performance and mobile devices.

## 🚀 Features

- **Responsive Design**: Fully adaptable to mobile, tablet, and desktop screens using Tailwind CSS.
- **Modern UI/UX**: Dark-themed interface with smooth scroll animations powered by Framer Motion.
- **SEO Optimized**: Includes meta tags, Open Graph tags, and semantic HTML structure.
- **High Performance**: Lightning-fast development and build process with Vite.
- **Component-Based**: Modular and reusable React components for easy maintenance.

## 🛠️ Tech Stack

- **React 18**: Component-based UI library.
- **Vite**: Next-generation frontend tooling for fast development.
- **Tailwind CSS**: Utility-first CSS framework for rapid styling.
- **Framer Motion**: Production-ready motion library for React animations.
- **Lucide React & React Icons**: Comprehensive icon sets for modern interfaces.

## 💻 Installation Steps

To run this project locally, follow these steps:

1. **Clone the repository:**
   ```bash
   git clone https://github.com/portifystudio/Network-Developer-Portfolio.git
   ```

2. **Navigate to the project directory:**
   ```bash
   cd Network-Developer-Portfolio
   ```

3. **Install dependencies:**
   ```bash
   npm install
   ```

4. **Start the development server:**
   ```bash
   npm run dev
   ```

5. **Build for production:**
   ```bash
   npm run build
   ```

## 🌐 Deployment (Vercel)

Deploying a Vite project to Vercel is straightforward:

1. **Push your code to GitHub:** Ensure your project is in a GitHub repository.
2. **Log in to Vercel:** Go to [Vercel](https://vercel.com/) and connect your GitHub.
3. **New Project:** Click "Add New Project" and import your repository.
4. **Vercel will auto-detect Vite:** It should automatically set:
   - Framework Preset: `Vite`
   - Build Command: `npm run build`
   - Output Directory: `dist`
5. **Deploy:** Click "Deploy". Your site will be live in seconds!
